# Сервис для бронирования переговорных комнат

Фронтенд-приложение, содержащее функционал:

 - выбор офиса;
 - фильтрации переговрных комнат по дате, времени, продолжительности встречи, вместимости;
 - просмотра расписания конкретной комнаты;
 - бронирования переговорки на определенное время;
 - просомтра своих бронировний за определенный период времени;
 - отмены бронирования.

 ## Стек

**HTML/CSS**
**React**

## Локальный запуск

Проект разделен на двае части backend (был дан по условиям задания) и frontend (полностью спроектированная и реализованнная мной часть)

Подробная инструкция по запуску бэкенда находится по адресу 'backend/sever/README.md'

###Запуск frontend

1. Откройте второй терминал и перейдите в папку с фронтендом:
   ```bash
   cd frontend
   ```
2. Установите зависимости:
   ```bash
   npm install
   ```
3. Создайте файл `.env` в папке `frontend/` и укажите адрес бэкенда:
   ```env
   VITE_API_URL=http://localhost:3000
   ```
4. Запустите приложение:
   ```bash
   npm run dev
   ```

После запуска клиентская часть будет доступна по адресу: `http://localhost:5173`
